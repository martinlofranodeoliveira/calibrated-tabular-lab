# Contributing

Use synthetic fixtures only. Install the exact hash lock, run `python -m unittest discover -s tests -v`, then `sh scripts/ci.sh` for offline package and fresh-consumer gates. Keep supported bounds, status distinctions and dependency license scopes explicit.

Add a focused regression with independent expected evidence for a behavioral change. Do not require calibration improvement, hide undefined ratios, repair splits using test outcomes or equate an arbitrary exception with an intended negative result. Preserve raw generated-source provenance when coordinating larger changes.

No deployment, release or remote-message action is part of the project tests.
