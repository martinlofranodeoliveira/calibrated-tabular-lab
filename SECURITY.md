# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/martinlofranodeoliveira/calibrated-tabular-lab/security/advisories/new). Do not include credentials or private datasets. General contact is available through [Lofrano Tecnologia](https://lofranotecnologia.com.br).

Version0.1.0 is a bounded local experiment tool. Only cooperative owned local Linux directories are qualified. No hostile-parent filesystem, universal process cleanup, real-time or power-loss guarantee exists. Input is closed JSON; there is no model pickle, arbitrary expression, endpoint or executable loading. Inspect dependency notices and keep the qualified artifact closure intact.
